# Awesome DESIGN.md (reference library)

Vendored from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see LICENSE). This folder is reference material, not a design to copy wholesale.

## How to use

1. Pick 1-3 references whose audience and tone match the brief. For a developer portfolio, the closest are usually `references/linear.app`, `references/vercel`, `references/raycast`, `references/resend`, `references/cursor`.
2. Read each `references/<site>/DESIGN.md` for structure and rationale: token naming, type scale, radius system, component states, do/don't lists.
3. Borrow the *method* (how tokens are named and justified, how rules are written), not the brand. Never ship another company's palette, logo treatment, or signature layout as-is.
4. Write the project's own `DESIGN.md` at the repo root using the same format (YAML front matter tokens + prose rules), then build to it.
